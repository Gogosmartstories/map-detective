# محققة الخريطة

خريطة تفاعلية ثلاثية الأبعاد للكثافة السكانية في الوطن العربي، لدرس «التوزيع السكاني وكثافته في الوطن العربي» – الصف السادس.

- جولة مجسّمة تقترب من مناطق التركز والندرة وتعود إلى النظرة العامة.
- اكتشاف مفتاح الخريطة بالألوان.
- أربع مهام تفاعلية ولوحة اكتشافات.

صفحة واحدة ثابتة (`index.html`) لا تحتاج إلى بناء أو إعدادات.
